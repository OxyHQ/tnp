# REST API

Base URL (production): `https://api.tnp.network`
Base URL (dev): `http://localhost:4170`

The API is plain JSON over HTTPS, served by Bun + Express 5. Mutating endpoints require an Oxy access token in `Authorization: Bearer <token>`; the token is verified against `https://api.oxy.so` by `@oxy.so/core`'s `oxy.auth()` middleware. The local `User` document is created lazily on the first authenticated request, keyed by `oxyUserId`.

CORS is enabled for `https://tnp.network`, `https://www.tnp.network` and the Cloudflare Pages preview origin; `http://localhost:8170` is added only when `NODE_ENV` is not `production`.

All responses follow `{ error: 'human readable message' }` on failure with the appropriate HTTP status. Successful responses return the resource directly (no envelope).

### Rate limits, timeouts and headers

Every route except `/health` is rate limited per client address, and writes are also limited per Oxy account (`apps/api/src/middleware/networkLimits.ts` has the classes and numbers). Over the limit the API answers `429 { error: 'rate_limited', limit, retryAfter }` with a `Retry-After` header. Buckets live in memory, per task, capped in size; nothing about them is logged.

The client address is the peer the ALB saw: one `X-Forwarded-For` entry from the right per trusted hop (`TNP_TRUST_PROXY_HOPS`, 1 in production). Express's `trust proxy` stays off, so `X-Forwarded-Host` never reaches `req.hostname`. When that peer is inside Cloudflare's published ranges and `TNP_TRUST_CF_CONNECTING_IP` is on (the production default), `CF-Connecting-IP` is used instead; a client that reaches the ALB directly is keyed by its own address and cannot choose another. IPv6 clients are keyed by their /64.

`/dns/resolve` answers are cached in memory for at most 30 s (positive, never longer than the smallest record TTL) or 10 s (NXDOMAIN, NODATA, parking). A statement running longer than `POSTGRES_STATEMENT_TIMEOUT_MS` is cancelled, and a request still running after `TNP_REQUEST_TIMEOUT_MS` is answered `503 { error: 'timeout' }`.

Every response carries `Strict-Transport-Security`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-Frame-Options: DENY` and `Content-Security-Policy: default-src 'none'; frame-ancestors 'none'; base-uri 'none'`. The parking page's CSP additionally allows its one inline stylesheet by hash.

In production, errors are logged without query parameters or row values (`apps/api/src/utils/logError.ts`): class, SQLSTATE, constraint and stack frames only.

## DNS resolution (`/dns`)

These endpoints are public — anyone can ask the API to resolve a domain. They are the single source of truth that both `apps/dns-server` and the local `tnp` client query.

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/dns/resolve?name=&type=` | none | Resolve a domain. `type` is `A`, `AAAA`, `CNAME`, `TXT`, `MX`, `NS`, or `ANY` (default `A`). |
| GET | `/dns/tlds` | none | Active TLDs. Returns `Array<{ name, custom }>`. |

`/dns/resolve` response shape:

```json
{
  "name": "example.ox",
  "type": "A",
  "answers": [
    { "name": "example.ox", "type": "A", "value": "203.0.113.10", "ttl": 3600 }
  ],
  "overlay": {
    "relay": "wss://relay1.tnp.network",
    "available": true,
    "domainKey": "<base64 Ed25519>",
    "rotations": [],
    "chain": [{ "issuer": "<domain key>", "subject": "<node key>", "purposes": ["service-node"], "scope": "example.ox", "notBefore": 0, "notAfter": 0, "serial": 1, "signature": "<base64>" }],
    "kaCert": { "signer": "<node key>", "key": "<base64 X25519>", "role": "service-node", "scope": "example.ox", "notBefore": 0, "notAfter": 0, "serial": 1, "signature": "<base64>" }
  },
  "rcode": "NOERROR"
}
```

The contract is `DnsResolveResponse` in `@tnp/shared-types`, and it only grows — with one deliberate exception: transport v1 replaced `overlay.serviceNodePubKey`, an unsigned key the client used as-is (audit S3), with the key material above. `rcode` (`NOERROR` or `NXDOMAIN`) was added so a resolver can tell NODATA — the name exists, no records of that type — from a missing name; resolvers that predate it keep reading empty `answers` as they always did.

`overlay` is only present when the domain's service node is `online`, its last heartbeat is at most 90 seconds old (three missed 30-second heartbeats), the name has a registered domain key, and the node's key-agreement certificate has not expired. An online node without that key material still suppresses parking (NODATA), but gets no overlay.

**The client does not trust any of it.** It pins `domainKey` per name on first use, accepts a different key only through `rotations` signed by the pinned key, and verifies `kaCert` and `chain` against that key — for the name it derived itself, never a name the response supplies — before it runs a session handshake. A registry that substitutes the key is refused by every client that has used the name before. See [`docs/architecture/security.md` §1](./architecture/security.md).

The full answer rules — CNAME at a name, NODATA, NXDOMAIN, parking synthesis for unregistered native names and for registered labels with nothing at them, expiry enforcement — are specified in [`docs/architecture/resolution.md` §9](./architecture/resolution.md).

## TLDs (`/tlds`)

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/tlds` | optional | List active native TLDs as `{ _id, name, status, custom, createdAt }`. Reserved TLDs are never listed. |
| POST | `/tlds/propose` | required | Propose a new TLD. Body: `{ tld, reason }`. |
| GET | `/tlds/proposals` | optional | List proposals sorted by score (upvotes − downvotes). Each entry carries `userVote: "up" \| "down" \| null` and `proposedByMe: boolean` for the caller. No proposer identity is published. |
| POST | `/tlds/proposals/:id/vote` | required | Upvote / downvote a proposal. Body: `{ direction: "up" \| "down" }`. Cannot vote on your own. |
| DELETE | `/tlds/proposals/:id/vote` | required | Remove your vote. |

`tld` must match `^[a-z][a-z0-9]{0,19}$`. Creating a proposal also creates a `TLD` document with `status: 'proposed'`, so the namespace is reserved while the community votes.

## Domains (`/domains`)

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/domains?page=&limit=` | optional | Public directory of listed names, ordered by name. Default `page=1`, `limit=50`, max `limit=100`. Returns `{ domains, total, page, pages }` of `PublicDomain`. |
| GET | `/domains/search?q=` | optional | Substring search over listed names. Max 50 results. |
| GET | `/domains/check/:name/:tld` | optional | Native availability under the full native policy. Returns `{ domain, available, reason?, detail?, namespace: "tnp-native" }`, `reason` ∈ `registered \| reserved \| tld_not_available \| invalid`. A subdomain such as `a.b.ox` is `invalid`. Never answers for public-DNS names. |
| GET | `/domains/check/:domain` | optional | Same, but `:domain` is `name.tld`. |
| GET | `/domains/lookup/:domain` | optional | Public detail view with records. 404 if not registered. |
| POST | `/domains/register` | required | Register a domain. Body: `{ name, tld }`. Reserved TLDs are refused with `TLD_RESERVED`. |
| GET | `/domains/owned?page=&limit=` | required | The caller's domains, newest first, default `limit=20`. Returns `{ domains, total, page, pages }`; each domain has `expiryState` and `recordCount`, no records. |
| GET | `/domains/mine` | required | **Deprecated** — use `/domains/owned`. The caller's domains with every record embedded, unpaginated. |
| PATCH | `/domains/:id` | required | Owner settings. Body: `{ unlisted: boolean }` (`UpdateDomainSettingsRequest`). An unlisted name is left out of `/domains` and `/domains/search` but still resolves and still answers `/domains/lookup`. Returns the `OwnedDomain`. |
| POST | `/domains/:id/renew` | required | Renew a native registration by one year from the later of its expiry and now. Free, owner only, allowed when `expiryState` is `renewable`, `grace` or `expired`; otherwise `409` with a `code` (`not_renewable`, `no_expiry`, `not_native`, `conflict`). |
| DELETE | `/domains/:id` | required | Release a native domain (must be owner). Irreversible: deletes the registration, its records and its service node, and the name becomes registrable by anyone. Never used by the services layer. |

Public responses (`PublicDomain`) carry no owner identifier and no `createdAt`/`updatedAt`: when a name was registered and when its records last changed are the owner's to see. Owner responses (`OwnedDomain`) add `createdAt`, `updatedAt`, `unlisted` and `expiryState` — `active`, `renewable` (within 90 days of expiry), `grace` (up to 30 days after, still resolves) or `expired` — defined in `@tnp/namespace` and specified in [`naming.md` §4](./architecture/naming.md).

### DNS records (per-domain)

All record routes require auth and ownership of the parent domain.

| Method | Path | Description |
|--------|------|-------------|
| GET | `/domains/:id/records` | List all records for a domain. |
| POST | `/domains/:id/records` | Add a record. Body: `{ type, name, value, ttl?, priority? }`. `type` ∈ `A \| AAAA \| CNAME \| TXT \| MX \| NS`. |
| PUT | `/domains/:id/records/:rid` | Update fields on a record. The record that results from the merge is validated as a whole. |
| DELETE | `/domains/:id/records/:rid` | Delete a record. |

Records are rows in their own `dns_records` table, so `:rid` is the record's UUID as returned by the create call — not the parent domain's id.

Validation is `parseCreateDnsRecordRequest` / `parseUpdateDnsRecordRequest` in `@tnp/shared-types`, the same code the web editor runs. A refusal is `400 { error, code, field }`.

- `name`: `@` or labels relative to the domain (letters, digits, interior hyphens, one optional leading `_`), lowercased. A name ending in the domain itself is made relative. Wildcards are refused: the resolver matches names exactly.
- `A`: a strict dotted quad. `AAAA`: an IPv6 address. `CNAME`, `NS`: a hostname (≤ 253, labels ≤ 63, trailing dot dropped, lowercased, not an IP).
- `MX`: a priority 0–65535, either as `priority` with a bare host in `value` or as `value: "<priority> <host>"`. Stored as `"<priority> <host>"`.
- `TXT`: at most 2048 characters, no control characters.
- `ttl`: an integer 60–86400; `3600` only when absent.

Cross-record rules answer `409 { error, code }`: a CNAME cannot share its name with any other record (`cname_conflict`), exact duplicates are refused (`duplicate`), and a domain holds at most 100 records (`record_limit`). Mutations for one domain run one at a time behind `SELECT … FOR UPDATE` on the domain row, so two concurrent writers cannot both pass these checks.

## Domain keys (`/domain-keys`)

Each native name's **domain key** (Ed25519) is generated on the owner's device (`tnp domain key init <name>`) and is the root of every grant chain for that name. The registry publishes it; it is not the authority for it.

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/domain-keys/:name` | none | `{ name, domainKey, rotations }` for an active `label.tld`, or 404 (no key, reserved TLD, not two labels). Relays check service nodes against this. |
| POST | `/domain-keys` | required, owner | Body `{ name, domainKey, rotation? }`. First key: `201`. Same key again: `200`. A different key requires `rotation`, a statement signed by the **current** key retiring it in favour of `domainKey` with `issuedAt` later than the previous rotation and at most 300 s in the future: `200`, otherwise `403`. `400` for a malformed body, a non-canonical key, or a rotation when no key exists; `404` unknown name; `409` lost a concurrent write. |

There is deliberately no reset. A lost domain key cannot be replaced in-band, because a reset is indistinguishable — to a client that pinned the old key — from the takeover pinning exists to refuse. The last 32 rotation statements are kept.

## Service nodes (`/nodes`)

Service nodes register a domain in the overlay network so `tnp connect` clients can reach it through encrypted tunnels.

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| POST | `/nodes/register` | required | Register or update a service node. Body: `{ domainId, chain, kaCert }` — the grant chain (leaf first, rooted at the domain key) and the node's key-agreement certificate. Must own the domain. `409` if the name has no domain key yet; `422` if the material does not verify against it (defence in depth — clients verify independently). Upserts by `domainId`; `publicKey` becomes the node key. Nodes re-register with a fresh certificate before the current one expires (at most 7 days). |
| GET | `/nodes/:domain` | none | Look up a service node by `name.tld`. Returns `{ publicKey, connectedRelay, status, online }` or 404. `online` is computed from a 90 s heartbeat threshold; `connectedRelay` is `""` unless online. No timestamp is published. |
| POST | `/nodes/heartbeat` | required | Mark online. Body: `{ domainId, connectedRelay }`. Updates `lastSeen`, sets `status: 'online'`. |

## Relays (`/relays`)

Relays are operated by Oxy or by the community and brokered by the API. Their endpoints are advertised over a public list.

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/relays?operator=` | none | List live relays: heartbeat within 90 s, Oxy-operated first, then longest-registered. Optional `operator=oxy\|community` filter. |
| POST | `/relays/register` | required | Register or update a relay. Body: `{ endpoint, publicKey, capacity: { maxConnections, bandwidth }, location? }`. `endpoint` must be `wss://` on a public host. Upserts by `endpoint`. |
| POST | `/relays/heartbeat` | required | Mark active. Body: `{ endpoint }`. Must be the registered operator. |

## Client distribution (`/client`)

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/client/latest` | none | Latest TNP CLI release. Returns `{ version, dns, platforms: { 'darwin-arm64', 'darwin-x64', 'linux-x64', 'linux-arm64', 'windows-x64' }, checksums, signature, install: { unix, windows } }` (`ClientLatestResponse` in `@tnp/shared-types`). Clients act on `version` only and rebuild every URL from the fixed release scheme. |
| GET | `/client/install.sh` | none | The Unix installer script. Served as `text/plain`, `no-store`. |
| GET | `/client/install.ps1` | none | The Windows installer script. Served as `text/plain`, `no-store`. |

The installers are `apps/api/src/installers/install.{sh,ps1}`, filled in at startup with the version, repository and release signing key from `@tnp/shared-types`. They are the only installers: the web app's `get.tnp.network` branch redirects here.

In production the API also responds to `https://get.tnp.network` — when the `Host` header is `get.tnp.network`, the API rewrites `/install.sh` to `/client/install.sh`, `/ps` and `/install.ps1` to `/client/install.ps1`, and `/` to whichever matches the user agent (PowerShell gets `install.ps1`). That's how `curl -fsSL https://get.tnp.network | sh` works.

## Parking middleware

For requests whose `Host` is a TNP domain (e.g., `nate.ox`), the API serves an inline HTML "registered on / available on TNP" page **at the original URL** — no redirect. The page is rendered server-side based on whether the name exists in the database and whether the TLD is a custom TNP TLD. Hosts that match `localhost`, `*.tnp.network`, `*.oxy.so`, or `*.pages.dev` are passed through to the regular router.

This is why directly visiting `nate.ox` in a browser (after pointing DNS at the TNP resolver) shows the parking page at `nate.ox` instead of redirecting away.

## Auth model

The middleware is built once and reused across routes:

```ts
import { OxyServices } from "@oxy.so/core";
const oxy = new OxyServices({ baseURL: process.env.OXY_API_URL });
export const oxyAuth = oxy.auth();
export const oxyAuthOptional = oxy.auth({ optional: true });
```

Public DNS routes (`/dns/*`, `/client/*`, `/health`) use no auth. Mixed routes (`/tlds`, `/domains`, `/nodes`, `/relays`) use `oxyAuthOptional` so GETs work without a token, then individual handlers wrap mutating actions with a `requireAuth` guard:

```ts
function requireAuth(req: AuthRequest, res: Response, next: NextFunction): void {
  if (!req.user?.id) {
    res.status(401).json({ error: "Authentication required" });
    return;
  }
  next();
}
```

`req.user.id` is the `oxyUserId` returned by the Oxy access token. The local `User` document is created lazily on the first authenticated call by `findOrCreateUser(oxyUserId)`.

## Environment

| Variable | Default | Description |
|----------|---------|-------------|
| `PORT` | `4170` | API listen port. ECS injects `8080` explicitly. |
| `DATABASE_URL` | *none* | PostgreSQL connection string, database name included. No default on purpose: a wrong database is worse than a missing one, so the API refuses to start without it. |
| `NODE_ENV` | `development` | Runtime environment. It does **not** select the database — that is `DATABASE_URL`'s job. |
| `OXY_API_URL` | `https://api.oxy.so` | Oxy API base URL (token verification). |
| `TNP_NATIVE_EXPIRY_ENFORCED` | `false` | Only exactly `true` enables it. When on, a native name past its 30-day grace period is withheld: `/dns/resolve` answers it like an unregistered name (parking only, no records, no overlay) and the parking page says "expired, held". It is never released for re-registration. Off by default because enforcing expiry retroactively needs an approved owner communication first (#62). |
| `TNP_OXY_RELAY_OPERATORS` | *empty* | Comma-separated Oxy user ids whose relays the directory publishes as `oxy`. Everyone else is `community`; a relay's own claim is ignored. Empty means there are no Oxy-operated relays, and `tnp serve` then requires `--relay`. |
| `TNP_TRUST_PROXY_HOPS` | `1` in production, else `0` | How many proxies' `X-Forwarded-For` appends the rate limiter believes. Production trusts only the ALB. |
| `TNP_TRUST_CF_CONNECTING_IP` | `true` in production, else `false` | Use `CF-Connecting-IP` as the client address, for requests whose peer is a Cloudflare address. Off, every client behind one Cloudflare edge address shares a rate-limit bucket. |
| `TNP_CLOUDFLARE_IP_RANGES` | built-in list | Overrides the Cloudflare ranges the previous setting checks against. |
| `TNP_RATE_LIMIT_EXEMPT` | *empty* | Addresses or CIDRs exempt from per-address limits — TNP's own DNS server, which resolves every query through `/dns/resolve`. |
| `POSTGRES_STATEMENT_TIMEOUT_MS` | `5000` | Server-side statement timeout on every pooled connection. `0` disables it. |
| `TNP_REQUEST_TIMEOUT_MS` | `10000` | A request still running after this is answered `503`. `0` disables it. |
| `TNP_PARKING_IP` | *none* | A-record value returned for unregistered names on custom TLDs and as a fallback for record-less registered domains. There is deliberately **no** fallback: a stale literal would route every TNP query at a dead or attacker-controlled host, so when this is unset parking answers are omitted instead. In production it is the Elastic IP fronting the `tnp-dns` NLB. |
